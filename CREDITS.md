## Optional licensed art

`npm run import-art -- --zerie <dir>...` imports Zerie's Tiny RPG Character Asset Packs into `public/art/licensed/`, which overrides the CC0 units with fully animated attack, hurt and death frames. That folder is git-ignored because the packs' license forbids redistribution.
